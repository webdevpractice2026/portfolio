# Create Your Free Portfolio with GitHub Pages

Build a simple personal portfolio and publish it free on the web using **GitHub Pages**.

You do not need to purchase web hosting or a domain name to get started.

## What You Will Build

By following this guide, you will create a portfolio website that can include:

* Your name or professional name
* About Me
* Skills
* Projects
* Education or training
* Contact information
* Links to your work

Your finished website can be available at:

`https://YOUR-USERNAME.github.io/`

Replace `YOUR-USERNAME` with your GitHub username.

---

## What You Need

You need:

1. A free GitHub account
2. A web browser
3. Basic HTML and CSS knowledge
4. A portfolio project you want to customize

You can edit your files directly on GitHub. You can also use a code editor such as Visual Studio Code or another development environment.

---

# Step 1: Create a GitHub Account

Go to:

https://github.com/

Create a free account and choose a username.

Your username will become part of your GitHub identity and can also become part of your portfolio website address.

For example:

`student123`

can have a GitHub Pages website at:

`https://student123.github.io/`

Choose a username you are comfortable using publicly.

---

# Step 2: Create Your Portfolio Repository

After signing into GitHub:

1. Click the **+** button in the upper-right corner.
2. Select **New repository**.
3. Name the repository:

`YOUR-USERNAME.github.io`

For example:

`student123.github.io`

4. Set the repository to **Public**.
5. Select **Add a README file**.
6. Create the repository.

GitHub uses this special repository naming format for a personal GitHub Pages website.

---

# Step 3: Add Your Website Files

Your website should contain an `index.html` file.

A simple portfolio might eventually look like this:

```text
YOUR-USERNAME.github.io/
│
├── index.html
├── styles.css
├── images/
│   └── profile.jpg
└── README.md
```

### `index.html`

This is the main webpage.

It contains the structure and content of your portfolio.

### `styles.css`

This controls the appearance of your portfolio, including:

* Colors
* Fonts
* Spacing
* Layout
* Mobile responsiveness

### `images/`

You can use this folder for images that you have permission to use.

---

# Step 4: Customize the Portfolio

Replace the sample information with your own.

Consider adding:

### About Me

Briefly introduce yourself and describe what you are learning or what type of work interests you.

### Skills

List technologies and skills you have learned.

For example:

* HTML
* CSS
* JavaScript
* Python
* Git
* GitHub

Only list skills you can reasonably discuss or demonstrate.

### Projects

Show projects you have created.

For each project, consider including:

* Project name
* What it does
* Technologies used
* What you learned
* Link to the project
* Link to the source code

### Education and Training

Include relevant:

* Schools
* Courses
* Certifications
* Training programs
* Professional development

---

# Step 5: Turn On GitHub Pages

Open your repository.

Then:

1. Select **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, find **Source**.
4. Select **Deploy from a branch**.
5. Select your main branch, usually `main`.
6. Select the `/ (root)` folder.
7. Click **Save**.

GitHub will build and publish your website.

It may take a few minutes before the website becomes available.

---

# Step 6: Visit Your Portfolio

Your personal GitHub Pages website will normally be:

`https://YOUR-USERNAME.github.io/`

For example:

`https://student123.github.io/`

Congratulations! You now have a publicly accessible portfolio without purchasing web hosting.

---

# Step 7: Keep Improving It

Your portfolio does not have to be finished the first time you publish it.

Continue improving it as you learn.

You can add:

* New projects
* New skills
* Better navigation
* Responsive design
* JavaScript features
* Project screenshots
* Links to live projects
* Links to source code
* A downloadable résumé

Your GitHub repository keeps the history of your changes, so you can see how your work develops over time.

---

# Important: Protect Your Private Information

A GitHub Pages website is publicly accessible.

Do **not** put sensitive information in your repository or website, including:

* Passwords
* API keys
* Access tokens
* Private credentials
* Social Security numbers
* Financial information
* Private documents
* Confidential employer information

Think carefully before publishing personal contact information.

Never put a secret or password into your HTML, CSS, JavaScript, or GitHub repository.

# Using This Portfolio as a Learning Project

The purpose of this project is not simply to create a website.

It is an opportunity to practice real development skills:

**Write code → Save changes → Commit changes → Publish → Improve**

As you gain experience, you can learn to use Git locally, branches, pull requests, GitHub Actions, and other professional development tools.
