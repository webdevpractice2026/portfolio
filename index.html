Welcome to the Portfolio Project

A portfolio gives you a place to show what you are learning, what you have built, and the skills you are developing.

In this project, you will create a simple portfolio website using HTML and learn how to publish it online using GitHub Pages.

You do not need to purchase web hosting or a domain name to complete this project.

Project Steps

  1. Create a free GitHub account.
  2. Create your portfolio repository.
  3. Download or copy the portfolio template.
  4. Customize the HTML with your own information.
  5. Add your projects and skills.
  6. Commit your changes to GitHub.
  7. Enable GitHub Pages.
  8. Visit your portfolio online and continue improving it.

What You Will Learn

This project gives you practical experience with several important web development concepts.

  • How HTML creates the structure of a webpage
  • How CSS controls the appearance of a webpage
  • How to organize files for a web project
  • How Git tracks changes to your code
  • How GitHub stores and manages your project
  • How GitHub Pages publishes a website
  • How to create a portfolio that grows with your skills
